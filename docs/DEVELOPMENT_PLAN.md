## 2 技术基线（冻结）

| 层 | 选型 | 说明 |
|---|---|---|

## 4 开发流程（每个任务的六步）

```
认领 Issue → 建分支 → 本地自测 → 提 PR → 24h 内评审 → squash 合并 + 关 Issue
```

1. **认领**：Issue 下评论 `take`，加 `doing` 标签。一人同时只做一件事（WIP=1）。
2. **分支**：从最新 `main` 切出，生命周期 ≤ 2 天。
3. **自测**：DB 类任务必须在**空库**上从 `00_schema.sql` 重跑；数据类贴行数对比；查询类贴执行结果。
4. **PR**：标题 `[任务ID] 摘要`，正文用模板；单 PR ≤ 400 行（纯生成 SQL 除外）。
5. **评审**：24 小时内给结论，只看三件事：空库能否复现、是否破坏冻结接口、是否留下证据。
6. **合并**：squash merge，删分支，关 Issue。

**提交信息**：`<type>(<scope>): <摘要>`，type = feat/fix/docs/data/chore/test，scope = db/data/ops。

**每日节奏**：21:30 群里三行站会（昨天/今天/阻塞）；11/29、12/03 各一次 30 分钟同步会。

**冻结**：11/27 模式、12/01 查询与视图名、12/04 代码。冲突处理：一个文件一个 owner。

## 附录 A SQLite → PostgreSQL 转换决策

| SQLite 写法 | PostgreSQL | 决策 |
|---|---|---|
| `TEXT` 存 ISO8601（`+08:00`） | `timestamptz` | 导入 `::timestamptz`；统一 UTC 存储 |
| `TEXT` 业务主键（`BATT_001`、`SIM-PACK-0001`） | `text` | **不改 uuid 类型**，避免 27 表外键连锁改动 |
| `GLOB 'SIM-PACK-[0-9][0-9][0-9][0-9]'` | `~ '^SIM-PACK-[0-9]{4}$'` | 正则 |
| `julianday(x) IS NOT NULL` | 删除 | `timestamptz` 已保证 |
| `length(trim(x)) > 0` | `btrim(x) <> ''` | 或 `x ~ '\S'` |
| `RAISE(ABORT, ...)` 触发器 | `CHECK` / `EXCLUDE` / `PL/pgSQL` | 先声明式，后过程式 |
| `REAL` 电压/容量 | `numeric(10,4)` | 测量点用 `double precision` |
| `INTEGER` 0/1 | `boolean` | 语义化 |
| `PRAGMA foreign_keys = ON` | 删除 | PG 始终开启 |
| `datetime('now')` | `now()` | 统一时区 |

**触发器分诊纪律**：每条先回答“能不能用约束表达”。能，改约束并写反例；不能，才写 `PL/pgSQL` 并在文件头注明理由。
